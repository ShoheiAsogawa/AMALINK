# 奄美群島チャットボット用ナレッジ・スターターパック

更新基準日：2026-07-11  
対象：奄美群島の8有人島・12市町村  
用途：Dify、OpenAI API、各種RAG基盤、自治体・観光・移住・教育向けチャットボット

## 対象範囲

### 8つの有人島
1. 奄美大島
2. 加計呂麻島
3. 請島
4. 与路島
5. 喜界島
6. 徳之島
7. 沖永良部島
8. 与論島

### 12市町村
- 奄美大島地域：奄美市、龍郷町、大和村、宇検村、瀬戸内町
- 喜界島：喜界町
- 徳之島：徳之島町、天城町、伊仙町
- 沖永良部島：和泊町、知名町
- 与論島：与論町

加計呂麻島、請島、与路島は瀬戸内町に属する。

## このパックの目的

単なる観光案内ではなく、次の質問に対応できる基礎層を作る。

- 奄美群島と奄美大島の違い
- 島ごとの自然・地形・文化・言語・歴史
- 世界自然遺産と国立公園の範囲
- 観光、体験、食、特産品、交通
- 暮らし、移住、行政、防災
- 島同士の比較と周遊計画
- 自然保護、集落訪問、祭祀・撮影のマナー

## 重要な設計原則

1. **島を取り違えない**
   - 回答には原則として島名と市町村名を併記する。
   - 「奄美」は奄美大島だけを意味する場合と、奄美群島全体を意味する場合があるため確認する。
2. **安定情報と変動情報を分離する**
   - 安定：地理、歴史、文化、自然、用語
   - 変動：時刻、料金、運航、営業、イベント、人口、道路規制、医療当番
3. **世界自然遺産と国立公園を混同しない**
   - 世界自然遺産の奄美側構成地域は奄美大島と徳之島。
   - 奄美群島国立公園は喜界島、沖永良部島、与論島なども含む。
4. **集落差を前提にする**
   - シマグチ、島唄、踊り、祭祀、食文化は島内でも集落により異なる。
5. **自然・文化のセンシティブ情報を細かく出しすぎない**
   - 希少種の営巣地、繁殖地、非公開祭祀、私有地、洞窟入口など。
6. **最新情報は公式確認を促す**
   - 航空・船便、百合ヶ浜、洞窟・海況、台風、イベントは必ず最新確認。

## 推奨データセット分割

- `01_stable_core`：地理、歴史、文化、自然、用語
- `02_island_guides`：島別・市町村別
- `03_facilities`：観光地、博物館、飲食、宿泊、体験
- `04_transport_dynamic`：航空、船、バス、レンタカー
- `05_events_dynamic`：祭り、イベント、季節体験
- `06_life_admin`：移住、医療、教育、行政
- `07_safety_realtime`：気象、避難、道路、海況

## 推奨チャンク

- 1チャンク：1テーマ、300〜800文字
- 島の概要：1島1〜3チャンク
- 市町村：1市町村1チャンク
- 観光施設：1施設1チャンク
- 生物：1種1チャンク
- FAQ：1質問1回答
- 交通：1路線・1運航区間1チャンク
